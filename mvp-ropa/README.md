## Como ponerlo a funcionar
1. Copiar la carpeta en `C:\xampp\htdocs\`
2. Importar `basedatos.sql` desde phpMyAdmin
3. Crear el archivo `config/conexion.php` con:
   usuario, clave, base de datos y puerto 3307
4. Abrir `http://localhost/mvp-ropa/`
